# student_grade_calculator

Universal UCT mark calculator - works for any course.

## How to run it
1. Download student_grade_calculator.py
2. Run it: python student_grade_calculator.py
3. Follow the prompts - enter your course, your CR components, and your exam info.

## What it does
- Calculates your Class Record from any number of components
- Checks if your CR weightings add up to 100%
- If you HAVE written the exam: calculates Final Mark + checks 40% exam subminimum
- If you HAVE NOT written the exam: tells you exactly what % you need on the exam to get 50% final
